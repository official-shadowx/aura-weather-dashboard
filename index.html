Troubleshooting & Architecture Guide:

  • Data Provider: Open-Meteo REST APIs (Geocoding, Forecast, Air Quality). No secret API key required.
  • Canvas Animation Engine: Driven by HTML5 2D Context (`requestAnimationFrame`) rendering weather particles according to live weather codes (WMO standard).
  • Glassmorphism & Scroll: Card blur effects use CSS `backdrop-filter: blur(16px)`. Scroll reveal uses native `IntersectionObserver`.
  • Handling API Errors: If search or network drops, check console logs above or verify internet connectivity. Open-Meteo returns HTTP 200/400 JSON payloads.
